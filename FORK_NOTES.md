# Ensrick QuickLootIE fork

This repository follows [MissCorruption/QuickLootIE](https://github.com/MissCorruption/QuickLootIE),
which descends from Eloquence4/QuickLootEE and SVG1/QuickLootRE.

## Branches

- `main`: maintained QuickLootIE line for Skyrim SE/AE, including 1.6.1170.
- `master`: historical QuickLootEE line retained for ancestry and comparison only.

## Local changes

- The default configuration excludes the Alternate Start - Live Another Life vanilla-start
  skeleton so its scripted activation path is not bypassed.
- Release publication is manual. Updating `main` does not automatically publish an untested
  nightly build.
